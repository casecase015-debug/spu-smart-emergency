# spu-smart-emergency
SPU Command Center

Modern Emergency Communication & Command Center Platform for Educational Institutions

Overview

SPU Command Center เป็นแพลตฟอร์มศูนย์บัญชาการและติดตามข้อมูลการสื่อสารฉุกเฉิน ที่ออกแบบมาเพื่อสนับสนุนการบริหารจัดการข้อมูล การติดตามเหตุการณ์ และการจัดเก็บบันทึกการสื่อสารภายในองค์กรการศึกษา

ระบบถูกพัฒนาด้วยแนวคิด Modern Dashboard UI เพื่อให้สามารถเข้าถึงข้อมูลสำคัญได้อย่างรวดเร็ว มีความทันสมัย ใช้งานง่าย และรองรับการแสดงผลบนอุปกรณ์หลากหลายประเภท

Installation

Clone Repository

git clone <repository-url>
cd spu-command-center

Install Dependencies

npm install

Start Development Server

npm run dev

Application will be available at:

http://localhost:5173

⸻

Build Production

npm run build

Build output will be generated in:

dist/
